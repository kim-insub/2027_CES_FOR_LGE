RF 리모컨 검사 프로그램

ESP32-C6 SuperMini + CC1101 RF 8키 보드 · UART 115200 8N1 · 호스트 프로토콜(0x00 → DEVICE_ID, 키 뗄 때 인덱스 / 길게 = +0x80)

지원 안 됨 이 브라우저는 Web Serial을 지원하지 않습니다. Chrome 또는 Edge에서 이 파일을 열어 주세요.

1. 연결

연결 안 됨
연결하면 1초 대기하면서 수신 잡음(부팅 문구)을 확인한 뒤 0x00을 보내 ID를 읽습니다 — 검사용 EXE와 같은 순서입니다.

2. 검사 결과

·
DEVICE_ID 응답 --
연결 후 자동으로 확인합니다.
·
수신 잡음 없음 (부팅 문구가 ID로 읽히지 않는지)
연결 후 1초 동안 확인합니다.
·
키 입력 확인 0 / 16
각 키를 짧게(0.6초 미만) 한 번, 길게(0.6초 이상) 한 번 눌렀다 떼세요. 길게 = 0x80 비트.
·
잘못된 바이트 없음
범위를 벗어난 값이 오면 여기에 표시됩니다.
